# v0.2.0 问答后端分包

本地开发版，2026-11-18。按用户请求从入口到数据访问分包，统一目录职责。本版基于 `pre-repackage-v0.2.0`，沿用已合并的 228 条知识、已审核的空值填充与展示价格问答。

## 问答如何经过各层

`app.py` 和 `python -m qa` 分别交给 `qa/router` 里的 Streamlit 和命令行处理。`qa/bootstrap.py` 读取配置，选择演示仓库或实际数据库仓库，再把仓库和模型客户端交给 `QAService`。服务解析问题、校验筛选条件，通过仓库读取事实或知识，整合来源后返回 `QAResponse`。页面或命令行显示回答，会话保存本轮使用的条件和结果顺序。

| 包 | 职责 | 主要模块 |
|---|---|---|
| `router` | 接收输入、管理交互会话、呈现回答 | `cli.py`、`streamlit_ui.py` |
| `service` | 问题理解、查询编排、证据和回答 | `chat.py`、`understand.py`、`answer.py` |
| `schemas` | 查询条件、回答与知识片段的 Pydantic 契约 | `query.py`、`response.py` |
| `models` | 会话状态、数据快照、价格与筛选规则 | `conversation.py`、`dataset.py`、`product_rules.py` |
| `repository` | 事实与知识访问接口、SQL/Cypher 查询和演示数据查询 | `contracts.py`、`mysql.py`、`neo4j.py`、`demo.py` |
| `db` | 数据库连接、只读事务、字段映射、正式快照读取 | `mysql.py`、`neo4j.py`、`mysql_tables.py`、`snapshot.py` |
| `clients` | 大模型及 Embedding 契约与 HTTP 调用 | `contracts.py`、`http.py` |
| `core` | 配置、异常、项目路径与别名标准化 | `config.py`、`errors.py`、`paths.py`、`text.py` |

以“300 元以下的葡萄酒”为例，`service` 得到预算上限，`repository` 读取候选产品，`models/product_rules.py` 核对价格和筛选条件。回答模板展示命中的酒款及价格性质。`db/mysql_tables.py` 的列映射同时用于在线一致性校验、离线 SQL 生成和数据库导入。

根目录 `database/` 保存建表和导入工具，`data_cleaning/` 保存离线清洗，`scripts/` 保存诊断和向量构建。离线工具从 `qa/db` 复用快照与映射逻辑。流程图见 [后端框架说明](../后端框架说明.md#2-模块边界)。

## 调用与迁移

可在项目根目录启动页面、进入命令行或检查已配置的数据库。

```powershell
python -m streamlit run app.py
python -m qa --interactive
python -m scripts.check_backend --online --require-vectors
```

Python 调用方可以直接从 `qa` 导入这三个对象。

```python
from qa import ConversationState, Settings, build_service

service = build_service(Settings.from_env())
try:
    response = service.ask("300元以下的葡萄酒", ConversationState())
    print(response.text)
finally:
    service.close()
```

| 旧代码路径 | 新代码路径 |
|---|---|
| `qa.config.Settings` | `qa.Settings`，实现在 `qa.core.config` |
| `qa.service.build_service` | `qa.build_service`，实现在 `qa.bootstrap` |
| `qa.service.QAService` | `qa.service.chat.QAService` |
| `qa.session.ConversationState` | `qa.ConversationState`，实现在 `qa.models.conversation` |
| `qa.mysql_repository`、`qa.neo4j_repository`、`qa.demo_repository` | `qa.repository.mysql`、`qa.repository.neo4j`、`qa.repository.demo` |
| `qa.models` 中的远程模型 | `qa.clients.contracts` 与 `qa.clients.http` |
| `qa.data`、`database.dataset` | 快照读取见 `qa.db.snapshot`，MySQL 列映射见 `qa.db.mysql_tables` |
